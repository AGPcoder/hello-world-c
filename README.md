👋 Hello World in C

A simple beginner-friendly Hello World program written in C. This project demonstrates the basic structure of a C program and how to display text on the console.

📌 About the Project

The Hello World program is one of the first programs commonly written when learning a programming language.

This project demonstrates some fundamental concepts of C programming, including:

Using header files

Defining the main() function

Displaying output using printf()

Returning a value from the program

Compiling and executing a C program

🛠️ Technologies Used

Language: C

Compiler/IDE: Embarcadero Dev-C++

Version Control: Git

Repository: GitHub

💻 Source Code
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

⚙️ Implementation Steps
1. Include the Standard I/O Library

The stdio.h header file is included to use standard input/output functions such as printf().

#include <stdio.h>

2. Define the main() Function

The main() function is the starting point of execution in a C program.

int main() {

3. Display the Message

The printf() function is used to display Hello, World! on the console.

printf("Hello, World!\n");


The \n escape sequence moves the cursor to the next line after displaying the message.

4. Return from the Program

The return 0; statement indicates that the program has completed successfully.

return 0;

5. Compile and Run the Program

The program can be written, compiled, and executed using Embarcadero Dev-C++.

Steps:

Open Embarcadero Dev-C++.

Create a new C source file.

Enter the program code.

Save the file as hello.c.

Compile the program.

Run the program.

Verify the output in the console window.

▶️ Output

After successfully running the program, the following output is displayed:

Hello, World!
